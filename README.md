# Painel de dados - GAQ

Solução local do painel de acompanhamento da GAQ.

## Repositório público

Este repositório guarda apenas o código e a configuração da solução.

Os ficheiros de dados reais não são versionados aqui:

- `dados.js`
- `tags.js`
- `dados.json`
- `tags.json`

Para executar localmente, mantenha esses ficheiros fora do Git e apenas no ambiente interno autorizado.
